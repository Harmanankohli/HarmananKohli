FinSight: Enterprise Multi-Agent Investment Intelligence Platform

Independent Personal Project · May 2026 – Present

Architected a multi-agent AI platform for investment research, orchestrating specialized agents for retrieval, quantitative analysis, market intelligence, analytics, and response validation.

  • Designed a framework-agnostic agent architecture using Google ADK, LangGraph, LangChain, LlamaIndex, CrewAI, PydanticAI, OpenAI Agents SDK, and the Agent-to-Agent (A2A) Protocol.
  • Implemented a unified Model Context Protocol (MCP) server exposing structured financial data, SEC filings, and external knowledge sources.
  • Built hybrid RAG with dense retrieval, BM25 search, reranking, metadata filtering, and persistent conversational memory.
  • Designed evaluation and observability pipelines using RAGAS and Langfuse to analyze retrieval quality, reasoning performance, hallucinations, and end-to-end system behavior.
  • Developed the platform using AI coding tools including Claude Code, OpenCode, and Mimo Code.
